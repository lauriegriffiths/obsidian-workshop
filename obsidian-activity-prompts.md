# Obsidian workshop: activity prompts

Work in your own vault or a copy of the workshop demo vaults. Fictional names and details are fine. You can also work on paper or follow along with a partner.

## 1. Something I keep forgetting

**Time: 3 minutes · Use your own vault · No plugins needed**

Think of something you have had to look up more than once. Create a note that would help next time.

For example: a printer cartridge, a useful command, a recipe adjustment, instructions for an appliance, or details of a place you visit.

1. Give the note a name you would recognise later.
2. Write the information you would want to find. If you don't know it yet, write the question you need to answer.
3. Navigate away from the note.
4. Find it again using search.

**Done when:** you can find your note and retrieve the information or question.

## 2. Today and its connections

**Time: 4 minutes · Use your own vault · No plugins needed**

Write a few sentences about today or yesterday. Include a person, a place, a project, or something you learned.

1. Create a note named with today's date.
2. Write your sentences as ordinary text. No properties needed.
3. Turn two things you might mention again into links using double brackets, such as `[[Maya Chen]]` or `[[Garden project]]`.
4. Open one of those links and add a useful sentence to its note.
5. Return to your daily note.

**Think about:** which information belongs to this particular day? Which would be useful whenever you open the person or project note?

**Done when:** you have a daily note connected to another note containing useful context.

## 3. Where did we meet?

**Time: 3 minutes · Use the Everyday demo vault · No community plugins needed**

You have just met Maya again. Use the notes to find out:

- Where did you meet her previously?
- What problem did she mention?
- What did you promise to do after your latest conversation?

Start wherever you like. Try search, follow links, or look at the backlinks to Maya's note.

**Done when:** you can answer the questions and show which notes contain the answers.

**Compare with a neighbour:** did you take the same route through the notes?

## 4. Make a project easier to resume

**Time: 4 minutes · Use your own vault or the Everyday demo vault**

Imagine you will return to a project after two weeks away. Leave yourself enough information to get started.

1. Create a project note. In the Everyday demo vault, put it in the `Projects` folder.
2. Write what you are trying to do, what happened last time, and one concrete next action.
3. Add `summary` and `work_time` properties. For this exercise, use `work_time` for manually entered total hours spent so far.

You can add properties through Obsidian's interface, or put this at the very top of the note and edit the values:

```yaml
---
summary: First sketch finished; ask for feedback next.
work_time: 1.5
---
```

**If Dataview is available:** open `Projects overview` in the Everyday demo vault. Find your project, change its summary in the source note, and revisit the table.

**Without Dataview:** compare your project's properties with another project note.

**Think about:** what could a table tell you quickly? What would you still need the full note for?

**Done when:** your note tells your future self what to do next.

## 5. Turn references into an idea

**Time: 5 minutes · Use the Game design demo vault · No community plugins needed**

Choose two reference notes. Make a new game concept that combines something from each.

1. Browse the notes in `References`.
2. Create a new note for your game concept.
3. Link to both references.
4. Describe what players do in a few sentences.
5. Write one question you would need to test.

**After three minutes, add this constraint:**

> A playtest suggests that one player has very little to do.

Add a possible change to your design and explain why it might help. Keep your original idea so you can see how your thinking developed.

**Done when:** your design note connects two sources and records a reason for a revision.

## 6. One owner, another site

**Time: 3 minutes · Use the Solar demo vault · No community plugins needed for the main activity**

Aki mentions another potential site. Create a note for it and connect it to the information you already have.

1. Create a new note in `Sites` and give it an invented name.
2. Add a link to the existing owner note: `[[Aki Mori]]`.
3. Write its current status and one unanswered question.
4. Open Aki's backlinks or local graph and find the new connection.

**Optional:** add an `owner` property containing `"[[Aki Mori]]"` and a `status` property so the site can appear with those details in the Dataview site table.

**If Map View is available:** copy a demo site's `location` property into your note and change the coordinates slightly. Find the new marker. Treat this as an invented location, not a real prospect.

**Done when:** the new site connects to the existing owner without copying the owner's contact history.

## Optional: move the work forward

**Time: 2 minutes · Use the Everyday demo vault · Kanban optional**

Imagine you sent Cedar Studio a request and are now waiting for a reply.

1. Open `Contact board`.
2. Move Cedar Studio's card from **Contact to make** to **Waiting for reply**.
3. Open the linked Cedar Studio note and write what you asked for.

If Kanban is unavailable, move the card's list item under the corresponding Markdown heading.

This is a fictional exercise; you do not need to send a message. Moving a card does not automatically update properties in the linked note.

**Done when:** the board shows the next state, and the note preserves the context.

## Closing: one thing for this week

**Time: 1 minute · Use your own vault**

Complete these sentences:

> This week, I'll use Obsidian to help me ______.
>
> The next thing I'll record is ______.

Choose something small enough to try today.
