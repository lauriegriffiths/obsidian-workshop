## Demos / デモ

- [Everyday life & work / 日常・仕事](vaults/01-everyday): people, projects, Dataview, Kanban / 人物・プロジェクト・表・ボード
- [Game design / ゲーム制作](vaults/02-game-design): references, ideas, revisions / 資料・アイデア・改訂
- [Solar prospects / 太陽光発電の候補地](vaults/03-solar): owners, sites, maps / 所有者・候補地・地図

Download the repository and open **one numbered folder** under `vaults` using Obsidian's **Open folder as vault**. Begin with `Start here`. Demo notes are in English and use fictional data. Install Dataview + Kanban for Everyday, Dataview + Map View for Solar; Game design needs no community plugins.  
リポジトリをダウンロードし、`vaults`内の**番号付きフォルダーを一つ**「保管庫としてフォルダーを開く」で開きます。`Start here`から始めてください。デモノートは英語で、データは架空です。EverydayにはDataviewとKanban、SolarにはDataviewとMap Viewを追加します。Game designはコミュニティプラグイン不要です。

## Presenting & printing / 発表・印刷

Slides retain Advanced Slides settings and image placeholders. Presenter cues remain HTML comments; convert them to `note:` for Advanced Slides' presenter view. The bilingual deck repeats each slide in Japanese, not the session duration. Print rendered cheatsheets on A4 portrait, about 10 pt with 12 mm margins and no browser headers/footers. Pagination depends on the renderer.  
スライドにはAdvanced Slidesの設定と画像用の空欄を残しています。発表者メモはHTMLコメントです。Advanced Slidesの発表者画面で使う場合は`note:`形式に変更してください。英日交互版でも講演時間は倍にはなりません。早見表は表示した状態でA4縦・約10pt・余白12mm・ブラウザーのヘッダーとフッターなしで印刷してください。改ページは表示アプリによって異なります。

English slides preserve the latest supplied text. Japanese slides and cheatsheets use copyable syntax: `---`, `[[Maya Chen]]`, full `https://` links, and closing code fences without a language name.  
英語スライドは最新の原稿を保持しています。日本語版と早見表では、`---`、`[[Maya Chen]]`、`https://`付きURL、言語名を付けない終了コードフェンスという、コピーして使える記法に整えています。
